## 五、顺带发现：`deleteProject` 的失败原先是静默的

原代码把 `fs.unlinkSync` 的异常全部吞掉（`catch (_) {}`），磁盘清理失败时服务日志里什么也看不到。已改为打印告警：

```js
try { if (fs.existsSync(fp)) fs.unlinkSync(fp); }
catch (e) { console.warn('[deleteProject] 删除票据文件失败 ' + fp + '：' + (e.code || '') + ' ' + e.message); }
```

排查过程中用「建测试项目 → 上传 → 删项目 → 查磁盘」的自清理脚本验证过这段逻辑：SQL 取 `file_path`、路径拼接均正确，**只是当前沙箱环境对文件删除有安全守卫**（`safe-delete-bulk-guard` 拦截了服务进程里的 `unlinkSync`），换成你双击 `启动报销系统.bat` 正常跑时会正常清理。
